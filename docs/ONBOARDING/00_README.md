# Onboarding — Tài liệu cho người mới vào nhóm

> Chào mừng bạn vào team IT — phụ trách module **Camera SOP Monitoring** của nhà máy.
> Bộ tài liệu này là "lộ trình đọc" trong 2 tuần đầu. Đọc theo thứ tự từ `01` đến `09`, mỗi file mất khoảng 20–40 phút.

## Cam kết khi đọc xong

Sau khi đọc xong 9 file + làm bài tập ở file `05`, bạn sẽ tự tin:
- ✅ Chạy được Hub ở 2 mode (`full` / `aggregator`).
- ✅ Đọc hiểu 1 Engine SOP mới (folder `core/engines/`).
- ✅ Thêm được 1 camera mới mà không phải hỏi ai.
- ✅ Phân biệt được code phần nào là của bạn, phần nào là của người khác.
